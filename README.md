# Simple Academic Website (Light/Dark)

Minimal, classic layout inspired by many academic pages, with a built‑in theme toggle.

## Deploy (GitHub Pages)
1. Create a public repo named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload these files.
3. Visit `https://YOUR_GITHUB_USERNAME.github.io/`.

## Customize
- Replace placeholders in HTML: `YOUR_EMAIL`, `YOUR_SCHOLAR_ID`, etc.
- Put your photo at `assets/img/profile.jpg` (currently blank).
- Add `CV.pdf` to the root.
- Edit publications and lists directly in `research.html` and `teaching.html`.

## Theme
- Click the 🌗 button (top right) to switch between light and dark. Preference is saved to `localStorage`.
- Default theme is light. To default to dark, add `data-theme="dark"` to the `<html>` tag.
