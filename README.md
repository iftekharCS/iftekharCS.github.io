# Academic Portfolio — Static GitHub Pages Starter

This is a minimal, clean academic portfolio site for **Md Iftekharul Islam** with **About**, **Research**, and **Teaching** pages.

## Quick start (GitHub Pages)

1. Create a new public repository named **`YOUR_GITHUB_USERNAME.github.io`** on GitHub.
2. Download this zip, unzip it, and upload the contents to that repository.
3. Commit to the **default branch** (usually `main`). For a user/organization site, Pages serves automatically at:  
   `https://YOUR_GITHUB_USERNAME.github.io/`
4. Visit the URL. If it 404s, give it a minute and refresh.

> If you use a project repo instead, go to **Settings → Pages** and set:
> - **Source:** `Deploy from a branch`
> - **Branch:** `main` (or your default)
> - Then the site will be at `https://YOUR_GITHUB_USERNAME.github.io/REPO_NAME/` — adjust links accordingly.

## Customize

- Replace placeholders in HTML (search for `YOUR_...`) — email, Scholar ID, LinkedIn, GitHub, etc.
- Replace `assets/img/profile-placeholder.svg` with your own image and update `index.html` `<img>` src if needed.
- Add your **CV** as `CV.pdf` in the project root (or update the link).
- Update publications and project links on `/research.html`.
- Update teaching info on `/teaching.html`.

## Optional extras

- **Custom domain:** Add a `CNAME` file at repo root with your domain (e.g., `example.com`), then configure DNS `A` and `ALIAS/ANAME` or `CNAME` per GitHub docs.
- **Analytics:** Paste your GA/Umami snippet before `</head>`.
- **No Jekyll:** A `.nojekyll` file is included to avoid special handling.
- **Accessibility:** Skip link + good contrast included; keep alt text updated for images.

## Develop locally

Open `index.html` in your browser. No build step needed.
